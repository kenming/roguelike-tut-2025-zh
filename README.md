# PyRogue2025

> 基於 **RoguelikeDev Tutorial 2025** 的中文化 Roguelike 遊戲開發學習專案

## 關於本專案

這是一個跟隨 [RoguelikeDev Tutorial 2025](https://rogueliketutorials.com/tutorials/tcod/v2/) 系列教學的學習專案，目標是從零開始建立一個完整的 Roguelike 遊戲，並加入中文支援。

### 特色
- 🔤 **中文支援** - 採用 TCOD + Pygame 混合渲染架構
- 📚 **學習筆記** - 每個章節都有完整的學習記錄和心得
- 🚀 **開發環境** - VSCode (含必要插件) + Python 3.13.5

### 個人發想與探索
- 🎨 **Emoji 視覺化** - 計劃嘗試用 🚶‍♂️👹🧱💰 等符號改善遊戲視覺體驗
- 🌍 **多語系支持** - 希望文字對話可以選擇繁體中文/簡體中文/英文界面，也可以讓玩家自行擴展它國語系
- 🔧 **模組化設計** - 想嘗試讓遊戲的語言包和視覺元素可以分離配置

> **說明**: 這些都是學習過程中的個人想法，會在掌握基礎功能後逐步嘗試實作與驗證
